## Содержание

Подготовлены два воспроизводимых функциональных дефекта для `error_user` и три дефекта для `visual_user`. Контрольное сравнение интерфейса выполнено с `standard_user`. Для каждого дефекта указаны шаги, ожидаемый и фактический результат, окружение, серьёзность и приоритет. Скриншоты получены в настоящем браузере Chrome; журналы и панель DevTools содержат фактически наблюдавшиеся сообщения.

## Проверка

1. Откройте SauceDemo. Это специально предназначенный для учебного тестирования сайт.
2. Войдите указанным в баг-репорте аккаунтом; учебный пароль сайта — `secret_sauce`.
3. Повторите шаги. Для сравнения вёрстки используйте область страницы 1440×1000.
4. Откройте F12 → Console и сравните сообщения с приложенными материалами.

`evidence/` содержит исходные снимки страниц, настоящую панель DevTools и JSON-журналы. `STANDARD_layout.png` — контрольный интерфейс. Цена для visual_user может меняться между входами, поэтому в отчёте зафиксирована пара цен одного сеанса.

Сетевое сообщение о недоступности Google Fonts относится к окружению и само по себе не подтверждает функциональный или визуальный дефект. Для визуальных дефектов исключения JavaScript не зафиксированы. Содержание рабочего сайта может измениться после указанной даты.
